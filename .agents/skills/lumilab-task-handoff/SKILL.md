# Task handoff

Read `AGENTS.md`, `docs/STATUS.md` and the assigned task. Inspect Git changes and confirm the owner and paths. Use an isolated branch or worktree when the task calls for one.

For handoff, record behavior, changed files, contract revisions, commands run, results, remaining dependencies and rollback. Record review, integration and deployment as separate milestones.
